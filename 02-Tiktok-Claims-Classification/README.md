# 📱 TikTok - Video Claims Classification & EDA

## 📌 Project Overview
TikTok's data team is developing a machine learning pipeline to classify user-submitted videos as either **claims** or **opinions**. As a Data Analyst, my goal in this phase was to perform **Exploratory Data Analysis (EDA)** to understand video attributes, user engagement metrics, and claim distribution patterns.

---

## 🛠️ Tech Stack & Tools
* **Language:** Python 🐍
* **Libraries:** `pandas`, `numpy`, `matplotlib`, `seaborn`
* **Business Intelligence:** Tableau (Interactive Dashboards)
* **Environment:** Jupyter Notebook

---

## 📊 Project Steps
1. **Exploratory Analysis in Python:** Imported datasets, cleaned missing values, and calculated summary statistics for verified vs. unverified users.
2. **Visual Data Exploration:** Plotted engagement metrics (likes, shares, downloads) across claim vs. opinion categories.
3. **Tableau Integration:** Designed interactive dashboards to map measure and dimension variables for executive reviews.
4. **Stakeholder Report:** Summarized core trends in user behavior to assist the Machine Learning team in feature selection.

---

## 💡 Key Findings
* Videos containing **claims** accumulate significantly higher view counts, shares, and likes compared to opinion-based content.
* Banned or under-review accounts are disproportionately associated with claim-type video uploads.
