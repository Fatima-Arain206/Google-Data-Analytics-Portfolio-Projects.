# 🚕 Automatidata - NYC Taxi Fare Prediction & EDA

## 📌 Project Overview
The **New York City Taxi and Limousine Commission (TLC)** partnered with Automatidata to build an automated system that estimates taxi fares for riders before their trip. In this phase of the project, I conducted **Exploratory Data Analysis (EDA)** using Python to clean, structure, and visualize the dataset for internal stakeholders.

---

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python 🐍
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Workflow:** Jupyter Notebooks / Google Colab

---

## 📊 Key Tasks & Methodology
1. **Data Loading & Cleaning:** Checked for missing values, duplicate entries, and inconsistent data types.
2. **Feature Engineering & Structuring:** Created custom dataframes and organized information to analyze ride distances, fare amounts, and payment types.
3. **Exploratory Data Analysis:** Built scatter plots, box plots, and histograms to identify fare distribution patterns and trip distance anomalies.
4. **Executive Summary:** Synthesized insights into a concise summary tailored for non-technical leadership at Automatidata.

---

## 💡 Key Insights & Recommendations
* Trip distances show a strong correlation with fare amounts, but drop-off locations and peak hours significantly impact total pricing.
* Credit card payments dominate transactions, providing cleaner data for automated fare estimation models.
