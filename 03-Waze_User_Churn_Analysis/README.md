# 🚗 Waze - User Churn Analysis & Retention Insights

## 📌 Project Overview
Waze is focused on reducing user churn to improve long-term retention and drive platform growth. In this exploratory project, I analyzed Waze user interaction data using Python to identify key behavior patterns that signal potential churn before users stop using the app.

---

## 🛠️ Tech Stack
* **Language:** Python 🐍
* **Libraries:** `pandas`, `numpy`, `seaborn`, `matplotlib`
* **Task Focus:** Data Cleaning, Outlier Handling, EDA, Data Visualization

---

## 📊 Workflow & Analysis
1. **Data Quality Check:** Cleaned raw GPS user logs, handled missing data, and managed extreme outliers in drive duration and distance.
2. **User Segmentation:** Segmented drivers based on activity levels, total driving days, and churn status.
3. **Exploratory Visualization:** Created heatmaps and distribution plots to highlight differences between retained and churned users.
4. **Insights Delivery:** Formulated an Executive Summary for the Waze leadership team.

---

## 💡 Core Insights
* User activity (number of drives and driving days per month) is the strongest indicator of churn.
* Users with high device usage but low completed drives show higher churn rates, pointing towards potential app usability issues.
