
#🚀 Google Advanced Data Analytics Portfolio Projects

Welcome to my Data Analytics & Python project repository! This repository contains end-to-end Exploratory Data Analysis (EDA) projects developed as part of the **Google Advanced Data Analytics** coursework. 

The goal of this portfolio is to solve real-world business problems across different domains using **Python**, **Data Visualization**, and **Business Intelligence** tools.

---

## 🛠️ Global Tech Stack & Tools
* **Programming Language:** Python 🐍
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Business Intelligence:** Tableau (Interactive Dashboards)
* **Environment:** Jupyter Notebooks / Google Colab / VS Code
* **Version Control:** Git & GitHub

---
. 🚕 Automatidata - NYC Taxi Fare Prediction
Objective: Analyze NYC TLC dataset to help estimate taxi fares prior to rides.

Key Tasks: Data cleaning, handling payment types, exploratory data analysis with Seaborn.

Outcome: Executive summary for Automatidata leadership on trip distance and fare correlations.

2. 📱 TikTok - Video Claims Classification
Objective: Explore user video submission data to differentiate between claims and opinions.

Key Tasks: Python EDA, engagement metric breakdowns, Tableau dashboard integration.

Outcome: Visual insights identifying engagement patterns among verified vs. unverified accounts.

3. 🚗 Waze - User Churn Analysis
Objective: Uncover driving interaction patterns that signal potential user churn.

Key Tasks: Outlier handling, user segmentation, activity trend visualizations.

Outcome: Strategic retention recommendations for the Waze data science team.
